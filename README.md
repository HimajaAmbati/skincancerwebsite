# Skin Cancer Awareness & Detection Website

A simple and interactive website to provide information about skin cancer and integrate AI-based detection.

## 🌐 Project Overview
This website is designed to **educate users about skin cancer** and provide a platform to analyze skin lesion images (when connected to ML backend). Users can:

- Learn about types and symptoms of skin cancer
- Upload images for analysis (optional AI model integration)
- Access prevention tips and healthcare guidance

## 🔧 Tech Stack
- **Languages:** HTML, CSS, JavaScript  
- **Frameworks/Libraries:** Tailwind CSS (for styling)
